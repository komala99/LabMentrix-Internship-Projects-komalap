# Facial Emotion Recognition using Deep Learning

## Overview
This project focuses on recognizing human facial emotions from grayscale images using a Convolutional Neural Network (CNN). The model learns facial features from the FER-2013 dataset and predicts one of seven different emotions.

## Project Goal
The main objective is to build a deep learning model that can automatically identify facial expressions and classify them into predefined emotion categories.

## Tools and Technologies
- Python
- TensorFlow & Keras
- NumPy
- Pandas
- Matplotlib
- OpenCV
- Google Colab

## Dataset
The model was trained using the FER-2013 facial expression dataset. The images are grayscale with a resolution of 48 × 48 pixels.

## Emotion Categories
- Angry
- Disgust
- Fear
- Happy
- Neutral
- Sad
- Surprise

## Model Architecture
The CNN model includes:
- Input Layer
- Two Convolutional Layers
- Two Max Pooling Layers
- Flatten Layer
- Dense Layer
- Dropout Layer
- Softmax Output Layer

## Project Workflow
1. Import required libraries
2. Load and preprocess the dataset
3. Explore the dataset
4. Build the CNN model
5. Train the model
6. Evaluate model performance
7. Predict emotions on new images
8. Save the trained model

## Outcome
The trained model successfully predicts facial emotions from input images. Training and validation performance were monitored using accuracy and loss graphs.

## Future Scope
- Improve accuracy using transfer learning models.
- Develop a real-time emotion detection application using a webcam.
- Deploy the model as a web application.
